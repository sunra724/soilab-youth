# 모닝챌린지 운영 가이드

모닝챌린지는 브라우저용 체험 화면이 아니라 초대코드 기반 참여 서비스다. 참여자의 체크인,
퀘스트 완료, 포인트, 동의 이력, 담당자 연결 요청을 Supabase에 저장한다.

## 제공 기능

- 홈페이지 우측 상단 `CSR` 메뉴와 `/csr` 프로그램 포트폴리오
- `/csr/morning-challenge` 모닝챌린지 사업 소개
- `/morning` 초대코드 등록, 오늘의 체크인, 퀘스트, 포인트, 참여 기록
- 선택형 AI 응원과 AI 미사용 고정 응원
- 담당자 연결 요청과 중복 요청 방지
- 익명·집계 성과 대시보드 예시 `/impact/demo`
- 서버 전용 세션 쿠키, 요청 제한, 감사 로그, 보유기간 만료 처리

`/impact/demo`의 수치는 영업 설명을 위한 명시적 예시 데이터다. 참여 서비스의 실제 기록과
섞이지 않는다.

## 최초 설정

1. Supabase 프로젝트를 만든다.
2. SQL Editor에서 `supabase/migrations/202607270001_morning_challenge_core.sql`을 실행한다.
3. `.env.morning.example`을 참고해 배포 환경변수를 등록한다.
4. 32바이트 이상의 무작위 `MORNING_SESSION_SECRET`을 만든다.
5. 초대코드를 발급한다.

```bash
node --env-file=.env.local scripts/create-morning-invite.mjs \
  --code SOILAB-START-2026 \
  --label "모닝챌린지 1기" \
  --uses 50 \
  --expires 2026-12-31
```

초대코드 원문은 데이터베이스에 저장하지 않는다. 담당자는 원문을 참여자에게 안전한 채널로
전달하고, 유출되었거나 모집이 끝난 코드는 `morning_invite_codes.active`를 `false`로 바꾼다.

## 운영 설정

`morning_settings`에서 다음 값을 운영 정책에 맞게 조정한다.

- `checkin_window`: 체크인 시작, 정상 인정 종료, 지각 인정 종료 시각
- `content_retention_days`: 참여자가 저장에 동의한 약속·응원 원문 보유일
- `minimum_impact_group`: 익명 성과를 표시할 최소 집계 인원
- `timezone`: 운영 기준 시간대

보유기간 만료 콘텐츠는 매일 아래 RPC를 호출해 지운다. Supabase Cron 또는 배포 플랫폼의
예약 작업에서 실행한다.

```sql
select morning_purge_expired_content();
```

## 개인정보와 안전

- 기업 화면에는 최소 인원 이상인 익명·집계 정보만 제공한다.
- 이름, 연락처, 약속 원문, 개인 출석 내역, 담당자 연결 요청을 기업에 제공하지 않는다.
- 참여자는 AI 응원과 약속 원문 저장을 각각 선택한다.
- 위험 가능 표현의 원문은 저장하지 않고, AI 대신 소이랩 고정 안내를 보여준다.
- 서비스 역할 키는 서버에서만 사용한다. 브라우저 코드나 공개 저장소에 넣지 않는다.
- 모든 모닝챌린지 테이블은 RLS를 켜고 `anon`, `authenticated` 직접 접근을 막는다.
- 이 서비스는 상담·진단·치료 서비스가 아니다. 긴급 안내 문구와 실제 연결 절차는 운영 전
  소이랩 책임자가 검토한다.

## 배포 전 점검

```bash
npm run lint
npx tsc --noEmit --incremental false
npm test
npm run build
```

배포 환경에서 다음 흐름을 실제 초대코드로 확인한다.

1. 신규 참여 등록
2. 같은 초대코드의 사용 한도 적용
3. 하루 한 번 체크인과 운영 시간 적용
4. 퀘스트 중복 완료 방지와 포인트 원장 기록
5. 담당자 연결 요청 생성
6. 로그아웃 후 기존 쿠키 재사용 차단
7. 모바일 360px 화면과 키보드 탐색

## 운영자가 알아야 할 현재 범위

- 초대코드는 스크립트 또는 Supabase 관리자 화면에서 발급한다.
- 담당자 연결 요청은 `morning_support_requests`에서 확인한다.
- 기업 성과 화면은 아직 예시 데이터다. 실제 성과 집계·내보내기는 별도 승인 후 연결한다.
- 쿠폰 발급과 정산, 사진·위치·걸음 수 인증, 알림톡·문자 발송은 포함하지 않는다.
- 지정기탁 수령기관, 기부금영수증 발급 주체, 후원금 예산 항목은 관계기관과 서면 확정한 뒤
  공개 문구와 운영 설정에 반영한다.
