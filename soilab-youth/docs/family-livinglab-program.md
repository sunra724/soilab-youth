## 기획 근거와 기존 사업에 대한 판단

첨부된 서울시 보도자료에는 교육 2회뿐 아니라 10가족 대상 가족별 최대 4회 상담·코칭, 가족 자조모임, 당사자 이해 체험, 피드백 워크숍도 포함된다. 따라서 전체 사업을 단순한 교육 행사로만 평가하는 것은 정확하지 않다. 다만 공개된 보도자료에는 참여자가 문제와 해결안을 결정하는 방식, 실제 생활 환경의 반복 실험, 실험 결과에 따른 개선과 서비스 도입 절차가 구체적으로 설명되어 있지 않다. 자료에 드러나지 않는 절차가 실제로 없다고 단정할 수는 없다. 예산 부족이나 개념 이해 부족 역시 확인된 사실이 아니다.

[교육 신청폼](https://docs.google.com/forms/d/e/1FAIpQLSegCiQ3DenvpGpdgyCV3q-UcvTLfoykvAshgKr8Jfaej6elBw/viewform?pli=1)은 브라우저에서 확인했다. 제목은 “2026년 고립은둔 청년 이해와 관계회복법 교육 신청”이며, 본문은 가족지원리빙랩의 교육 프로그램이라고 안내하고 후속 가족상담과 자조모임의 참여 의향도 묻는다. 이 폼은 전체 리빙랩의 설계·검증 문서가 아니라 교육 모집 단계의 안내로 해석하는 것이 적절하다.

ENoLL은 리빙랩의 중심을 사용자 공동창조, 실제 생활 환경의 실험, 다양한 이해관계자의 참여에 둔다. 참고: [ENoLL Living Labs](https://enoll.org/living-labs/).

소이랩의 영업 메시지는 공동 문제정의, 두 차례의 생활 실험, 개선 기록과 지역 도입 산출물을 구체적으로 보여주는 데 둔다. 타 기관의 의도나 전문성에 대한 추정은 공개 홍보 문구에 사용하지 않는다.

## 구매 대상과 제안 가치

- 지자체 청년·복지 담당부서: 지역 가족지원 사업의 설계와 실증, 다음 연도 사업에 활용할 운영 가이드.
- 청년센터·청년미래센터·복지기관: 가족의 부담을 낮추는 지원 경로와 청년의 선택권을 반영한 접촉·대화 도구.
- 지역재단·후원기관: 당사자 참여와 학습 과정을 확인할 수 있는 소규모 실증사업.

주요 메시지: “가족과 청년이 함께 문제를 정하고, 일상에서 해결안을 두 번 시험·개선해 지역이 이어갈 가족지원의 방법을 만듭니다.”

## 기본 규모와 운영 자원

기본형은 운영 12주에 종료 4주 후 점검을 더한다. 가족 참여팀 10~12가족과 청년 공동설계팀 4~6명을 기본 제안으로 하며, 청년팀에는 현재 고립을 경험하는 청년과 회복 경험 청년의 관점을 반영하도록 모집한다. 가족과 청년이 같은 자리에 출석할 의무를 두지 않는다. 청년팀의 자문은 실제 도구를 사용하는 개별 청년의 동의를 대체하지 않는다.

운영 역할은 총괄 책임자, 리빙랩 진행자, 가족 지원 담당자, 기록·평가 담당자로 구성한다. 역할의 겸임 범위와 상담 담당자의 자격·회차는 계약 전에 확인한다. 협력기관과 평가 자문은 확보된 것으로 홍보하지 않고 착수 전에 확정한다.

기본 운영량:

| 활동 | 제안 회차 | 목적 |
| --- | --- | --- |
| 공동 워크숍 | 8회, 회당 약 2시간 | 이해, 문제정의, 도구 제작, 실험 검토, 결과 확인 |
| 가족별 점검 | 가족당 2회, 회당 약 1시간 | 참여 준비와 상황별 실행 점검 |
| 청년 공동설계 | 4회 수준으로 협의 | 과제 선정, 시제품 검토, 개선, 결과 해석 |
| 실험 중 점검 | 실험 주간별 짧은 점검 | 선택한 문자·온라인·전화 방식으로 부담 확인 |
| 기관 협의 | 착수·중간·종료 3회 | 자원 확인, 연계 개선, 후속 운영 결정 |
| 후속 점검 | 종료 4주 후 1회 | 사용 지속 여부와 후속 지원 연결 확인 |

8회 워크숍은 1·3·4·6·7·9·11·12주 배치를 기본으로 한다. 가족별 점검은 초기와 중간에 배치하고, 청년 공동설계는 2·4·8·11주를 기준으로 참여 방식에 맞춰 조정한다. 주간 점검은 추가 출석 의무가 아니라 선택한 채널로 필요한 만큼 진행한다.

## 공동 의사결정

1. 가족과 청년이 각각 후보 과제를 제안한다. 진행자는 의견의 출처와 서로 다른 관점을 기록한다.
2. 참여자는 필요성, 실행 부담, 자신의 참여 의향을 기준으로 우선과제를 고른다. 이견이 있는 과제는 보류하거나 가족 자신의 지원 범위로 좁힌다.
3. 해결안은 직접 사용할 사람이 허용하는 행동·시간·연락 방식 안에서 만든다. 동의가 확인되기 전에는 실제 청년의 생활에 적용하지 않는다.
4. 첫 실험 후 각자의 피드백을 따로 받고, 공유가 허용된 내용을 토대로 유지·수정·중단을 결정한다. 진행자는 변경 전후와 이유를 기록한다.
5. 종료 보고서의 주요 해석은 참여자가 확인한다. 공개 가능한 범위와 사업의 다음 실행 결정은 구분한다.

## 생활 실험 기록 서식

| 항목 | 작성 내용 |
| --- | --- |
| 과제와 제안자 | 누가 어떤 생활 장면의 어려움을 제안했는지 |
| 기대 변화 | 작은 변화에 대한 가설, 효과가 확인되지 않았음을 표시 |
| 시제품 | 사용하는 카드·약속·연락 경로와 버전 |
| 직접 사용자와 동의 범위 | 누가 무엇에 동의했는지, 허용 행동·시간·정보 공유 범위 |
| 관찰 기간과 항목 | 부담, 사용 여부, 실행 조건, 예상 밖 반응 |
| 중단 조건 | 당사자의 중단 요청, 부담 증가, 관계 갈등 등 |
| 각자의 피드백 | 가족 응답과 청년 직접 응답을 구분해 기록 |
| 결정과 변경 이유 | 유지·수정·중단, 2차안에 반영한 내용 |

제안 예시는 연락 선호 카드, 대화 주제·멈춤 신호 카드, 가족의 도움 요청 경로다. 청년의 직접 동의가 없는 경우 가족 자신의 지원 요청이나 행동 성찰을 다룬다. 가족의 보고를 청년의 경험으로 대체하지 않는다.

## 평가와 납품

초기·종료·종료 4주 후에 같은 항목을 사용한다. 자체 점검 문항은 생활 변화 관찰용으로 표시하고 진단도구로 소개하지 않는다. 임상 척도가 필요한 사업은 해당 도구의 적용 조건과 전문 담당자를 별도로 협의한다.

- 가족: 스스로 평가한 부담, 도움을 요청할 수 있는 정도, 선택한 생활 과제의 실행 가능성.
- 청년: 직접 참여에 동의한 청년의 연락·대화 부담, 자신의 선택이 존중된 경험.
- 시제품: 동의한 사용자의 실제 사용 여부, 중단 이유, 개선 횟수와 변경 이유, 적용 가능한 조건.
- 기관: 응답 시간, 실제 서비스 연결 확인, 후속 담당자와 도입 결정.

보고에는 응답 인원, 미응답, 중단과 이탈 사유를 포함한다. 소규모 전후 비교로 인과 효과를 확정하거나 관계회복·취업 전환을 보장하지 않는다. 가족만 참여한 사례에서 청년의 변화가 직접 확인되지 않았으면 미확인으로 표시한다.

납품물은 공동 문제정의서, 과제별 도구와 사용 가이드, 두 차례 실험·개선 기록, 성과·학습 보고서, 기관 운영 가이드, 지역 후속 실행안이다. 공유·재사용 범위, 편집 가능한 파일 형식, 인쇄물 수량과 사례 공개 여부는 계약서에 명시한다.

## 참여와 기록 운영

참여·기록·기관 간 공유·외부 공개의 동의를 구분한다. 열람 담당자, 보관 기간, 삭제 절차를 착수 전에 정한다. 청년과 가족의 개별 응답은 각자의 허락 없이 상대에게 제공하지 않는다. 공개 보고에는 비식별 집계와 별도 동의한 사례만 담는다.

참여자는 쉬거나 중단할 수 있다. 생활 실험 중 부담이나 갈등이 커지면 중단하고 지원 담당자가 개별 지원과 전문기관 연계를 검토한다. 사업비에는 참여자의 접근 지원과 보상을 반영하고, 중단을 이유로 이미 참여한 활동의 정당한 보상을 박탈하지 않는다.

견적 항목은 운영 인력, 당사자 참여 보상, 공간·이동·온라인 접근 지원, 도구 제작, 평가·기록, 상담·연계, 후속 점검과 사업 관리로 나눈다. 예산을 줄여야 할 때에는 규모와 확산 범위를 조정하되, 공동 문제정의·직접 사용자의 동의·실험 후 개선·결과 기록에 필요한 자원을 먼저 확보한다.

홈페이지는 기관 담당자가 방식 → 12주 과정 → 실험 예시 → 산출물·평가 → 도입 범위를 읽고 문의할 수 있게 구성한다. 프로그램 상태는 “기관 도입 제안”으로 표시한다. 기본 규모·회차와 가상의 실험 예시는 확인된 성과와 구분한다.

메인 홈페이지와 기존 리빙랩 페이지에 소개 영역을 추가하고, 푸터와 사이트맵에 연결한다. 기관 문의는 기존 대표 이메일 `soilabcoop@gmail.com`으로 지역·시기·가족 수·예산 범위가 포함된 이메일 초안을 연다. 접수 기능이 있는 온라인 신청서로 오인시키지 않는다.

문의가 들어오면 지역 과제와 참여 기반을 확인하고, 운영 인력·청년 참여 경로·전문 지원·납품물 범위를 구체화한 제안서와 견적을 보낸다. 당사자 모집과 현장 운영은 계약·인력·동의 절차가 정리된 후 착수한다. 초기 실증에서 도구와 운영 조건을 확인한 뒤, 실제 결과와 한계를 근거로 확산안을 제안한다.
