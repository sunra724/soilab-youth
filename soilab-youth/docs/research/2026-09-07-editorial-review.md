# 첫 연구자료 검토 기록

확인일: 2026-09-07. 원문 전체를 읽었다고 표시하지 않고, 확인한 장과 쪽수를 공개 요약과 연구노트에 기록했다. 검토 요약은 `2026-09-07-source-reviews.json`, 연구노트는 `src/data/research-notes.ts`에 보관한다.

## 자료와 확인 방법

- 청년의 사회적 고립 실태 및 지원 방안 연구: 유민상·신동훈, 한국청소년정책연구원, 2021. [원문 PDF](https://www.nypi.re.kr/repository/bitstream/2022.oak/2931/2/R07.pdf). 본문 11, 19~21, 36~37, 54, 472~474쪽 확인.
- 아동·청소년의 사회적 고립 실태 및 대응 방안 연구: 유민상·서고운·신동훈·이지연, 한국청소년정책연구원, 2023. [원문 PDF](https://www.nypi.re.kr/repository/bitstream/2022.oak/6275/2/23-%EC%88%98%EC%8B%9C03.pdf). 본문 5, 35~37, 72~74, 76~79, 86~87쪽 확인.
- 고립·은둔형 청소년 실태 및 지원방안 연구: 서정아·강경균·최홍일·허창수, 한국청소년정책연구원. [원문 연결 페이지](https://www.nypi.re.kr/repository/handle/2022.oak/6527). 본문 159~162, 187~188, 239~241쪽 및 판권 확인.

NYPI에서 PDF를 직접 내려받아 텍스트를 추출하고, 주요 표와 판권은 페이지 이미지도 확인했다. 원문 파일과 추출본은 비공개 `.local/research/editorial/`에 두며 사이트에 재배포하지 않는다. 공개물에는 독자적으로 작성한 짧은 요약·해석과 발행기관 링크를 제공한다. NKIS 수집 원문 메타데이터는 그대로 유지한다.

## 발견한 쟁점

1. 2021년 보고서의 표 Ⅰ-1(11쪽)은 표본수를 2,014명으로, 본문 36·54쪽은 2,041명으로 적고 있다. 렌더링한 11·36쪽에서도 같은 차이를 확인했다. 오기라고 단정하지 않고 불일치와 원자료 확인 필요성을 공개했다. 표본 크기를 근거로 비율을 다시 계산하지 않았다.
2. 2023년 연구는 현장 전문가 16명 면접이며 당사자 면접을 실시하지 않았다. 눈덩이 표집과 후속 연구 필요성을 기록했다. 새로운 전국 실태조사로 소개하지 않는다.
3. 고립·은둔형 청소년 연구는 연구번호와 조사연도가 2024이나 PDF 판권의 발행일은 2025-06-30이다. NKIS와 NYPI 도서관은 2025, NYPI 리포지터리 메타데이터는 2024다. 출판연도는 판권에 맞추고 조사연도·서지 차이를 별도로 설명했다.
4. 9~24세 온라인 자발적 참여 조사의 본조사 완료자는 2,139명이다. 이 비율을 전국 또는 대구 청년의 규모로 환산하지 않는다.
5. 연구의 정책 제언과 센터의 운영 제안을 구분한다. 연구노트의 연락·기록 절차는 검증된 효과나 시행 중인 센터 사업을 뜻하지 않는다.

## 공개 및 운영 확인

검토 API의 원문 해시 조건을 사용해 해당 3건만 공개한다. 나머지 자료는 검토 대기로 남긴다. 연구노트에서 세 자료의 요약과 원문으로 연결하고, 사이트맵에 승인 자료와 연구노트를 포함한다.

Vercel 운영 프로젝트에서 오전 7시(KST) 브리핑 예약 `0 22 * * *`와 활성화된 cron 설정을 확인했다. 법령 수집은 매일 06:00, NKIS 수집은 월요일 06:15(KST)다. 2026-09-08 오전 7시의 실제 예약 실행 여부는 해당 시각 이후 배포 로그와 그 날짜의 브리핑 상태·텔레그램 기록을 확인해야 한다. 이 기록은 미래 실행을 확인했다는 뜻이 아니다.

## 완료 확인

- 3건의 검토 API 승인이 성공했고, 재조회 결과 승인 3건·대기 8건이다. 공개 자료 API는 기존 색인 6건을 포함해 9건을 반환한다.
- 운영 배포 `dpl_48oKZeXwwsYAXPtiZGLhHdrr5N57`을 완료했다. https://www.soilab-youth.kr/research/notes/outreach-to-first-connection 에서 연구노트를 확인할 수 있다.
- 연구노트·목록·자료 3건·사이트맵 HTTP 200, 없는 연구노트 HTTP 404를 확인했다. 사이트맵에 승인 자료 3건과 연구노트가 포함된다.
- 관련 기존 테스트 15개, ESLint, Next.js 프로덕션 빌드와 빌드 내 TypeScript 검사가 통과했다.
- Playwright와 설치된 Edge로 운영 페이지를 열어 PC 1440px·모바일 390px 화면을 확인했다. 페이지 전체의 가로 넘침이 없고 브라우저 실행 오류가 없었다. 본문 출처 링크 3개와 출처 앵커 이동을 확인했다. 모바일 표는 내부 가로 스크롤로 마지막 열까지 확인했다.
- 새 배포에도 세 연구 수집·브리핑 예약이 연결되어 활성화되어 있다. 오늘 브리핑은 계속 `delivered` 상태이며 이번 작업에서는 추가 메시지를 발송하지 않았다.
