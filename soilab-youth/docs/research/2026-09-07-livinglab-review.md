# 청년센터 리빙랩 구성 검토

사용자 요청: 전체 사이트 구성에 맞게 리빙랩 페이지를 검토하고 필요한 부분을 수정한다.

## 검토 결과

리빙랩 메뉴는 사업·정책연구·성과 사이에서 청년과 현장이 함께 시도하고 배우는 과정을 설명하는 역할로 유지한다. 기존 본문은 기관 대상 실증사업 안내, 미입력 KPI 6개, 도입 패키지 5개가 비중을 차지해 영업 안내·성과 메뉴와 겹쳤다.

## 반영한 구성

- 첫 화면: 청년과 함께 일상회복의 방법을 찾고 실험한다는 설명과 본문 이동 버튼.
- 소개: 경험 듣기, 공동설계, 작은 시도, 돌아보기라는 의미를 쉬운 말로 설명.
- 현장 질문 8개: 질문형 제목, 실험 제안 표시, 관련 연구노트 3편 연결. 별도 관찰 기록이 확인되지 않은 2개 카드의 ‘현장 관찰’ 표시는 ‘실증 가설’로 조정.
- 함께하는 과정: 경험 듣기 → 질문 정리 → 함께 설계 → 작은 시도 → 살펴보기 → 배운 점 나누기. 앞 단계로 돌아갈 수 있음을 설명.
- 회복의 변화: 기존 단계 번호와 연결선을 걷어내고 선택·일상·관계 등 살펴볼 영역으로 제시. 검증된 평가 척도나 정해진 통과 순서로 표현하지 않음.
- 기록과 배움: 공개된 개별 실험이 아직 없음을 밝히고, 기록할 질문·방법·변화·다음 시도를 안내. 향후 공개된 사례에는 기간·배운 점·다음 시도도 표시하도록 구성.
- 지역 협력 역할은 펼침 영역으로 제공하고 FAQ를 청년·가족·실무자 관점으로 수정.
- 지원 문의처는 `/research/support`, 원문 근거는 `/research`, 센터 성과는 `/#stats`, 기관 정책·사업 검토는 소이랩 포털 `/stream`에 연결.

메뉴명·주소는 유지했다. 이전 본문 앵커 `#outcomes`와 `#packages`도 관련 연결 영역으로 유지했다. KPI·패키지의 기존 데이터와 필터는 보존했으며 수치·사례를 새로 승인하거나 다른 사이트에 자동 발행하지 않았다. 상세 운영 방법은 `docs/livinglab-data-guide.md`에 반영했다.
