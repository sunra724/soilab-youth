### 원문 대조

1. 한국청소년정책연구원 2023년 『아동·청소년의 사회적 고립 실태 및 대응 방안 연구』: 본문 76~77·80~81·86~87쪽 = PDF 90~91·94~95·100~101쪽. 부모 상담·교육·자조모임 제언과 다양한 평가 지표, 생애주기 연결, 전문가 면접과 당사자 면접 부재라는 한계를 확인했다. 기존 로컬 PDF의 페이지별 추출 텍스트와 이전 검토 화면을 이용했다.
2. 일본 후생노동성 『ひきこもり支援ハンドブック』(2025.1), 제2장: 본문 14~15쪽 = 분할 PDF 2~3쪽. 본인의 삶과 사회관계를 스스로 결정하는 목표, 의사 표현과 선택에 대한 지원을 확인했다. https://www.mhlw.go.jp/content/12000000/001471258.pdf
3. 같은 핸드북 제4장: 본문 27·29·36~38쪽 = 분할 PDF 1·3·10~12쪽. 지원 진입 경로의 다양성, 가족 상담, 가족 정보 취급과 신뢰, 지원의 변동과 지속성을 확인했다. https://www.mhlw.go.jp/content/12000000/001471260.pdf

제2·4장 PDF를 공식 사이트에서 다시 내려받아 텍스트를 확인하고 일부 쪽을 PNG로 렌더링해 검토했다. 국내 성인 청년에게 보편적으로 효과가 입증된 기법으로 표현하지 않았다. 일본 자료는 부분 검토와 비공식 한국어 요약임을 표시했다. 자료실의 일본 핸드북 확인 범위도 이에 맞게 갱신했다.

## 지원 문의 안내

- `/research/support`에 대구청년센터 성장지원팀 053-427-1934, 청년센터 공고 목록, 전국 사업 지역 접수 확인을 위한 129·청년ON 경로를 안내했다.
- 대구시 공식 공고(2026-02-10, nttId=786666)에서 19~39세 청년·가족, 상담 기간 2026-02-24~03-26, 담당 번호, 청년·가족별 신청 절차를 확인했다. 해당 차수는 이미 지났다고 명시하고 지난 신청 양식으로 유도하지 않았다.
- 공식 사이트 본문 직접 요청은 연결 오류가 있어 웹 검색에 색인된 **대구시 공식 공고 본문**으로 위 내용을 대조했다. 청년센터 공식 채널·공고의 같은 담당 번호도 확인했다. 전화 연결, 현재 잔여 정원, 최신 모집 차수의 신청 완료는 검증하지 않았다.
- 정부 2026-07-21 안내의 19~34세 고립·은둔청년 사업, 9월 전국 확대, 신청 경로를 직접 확인했다. 자기돌봄비는 가족돌봄청년 별도 지원으로 구분했다.
- 대구 청년미래센터 실제 접수기관·개시일은 확정하지 못해 문의 경로를 안내했다. 상세 법령 절차 초안은 지역 접수·운영지침 확인이 남아 있다. 현재 공개 페이지는 확인된 문의 안내다.

## KOSIS 통계

- 기존 로컬 키로 API를 재조회해 DT_1SSSP041R 8행, DT_1SSSP050R 8행, DT_417001_0035 6행, 총 22행을 확인했다.
- 공개 JSON의 모든 값이 조회 원본의 DT 문자열과 일치하는지 대조했다. 비밀 키·조회 URL 매개변수·원문 PDF는 공개 데이터에 넣지 않았다.
- 사회적 관계망: 전국 19~29·30~39세. 집안일 도움 문항 전체는 19세 이상, 이야기 상대 문항 전체는 13세 이상.
- 외로움: 전국 20~29·30~39세, 전체는 13세 이상. 두 표의 대구 자료는 전체 연령이며 청년 교차값은 조회되지 않았다.
- 사회적 고립감: 전국 19~29·30~39세와 19세 이상 전체, 문항별 평균 1~4점. 전체의 ‘아무도 자신을 잘 알지 못한다’ 값도 원본대로 **1.7점**이다. 이 표에는 대구 차원이 없다.
- 대구 전체 자료는 펼침 영역으로 구분했다. 고립·은둔청년 인구 추정, 임의 연령 합산, 결측 0 처리, 다른 문항의 합산을 하지 않았다.
- 공개본은 검토한 2025년 스냅샷이며 KOSIS 실시간 자동 발행이 아니다. 다음 갱신은 API 조회 → 로컬 후보 생성 → 주석·범위 검토 → 공개 JSON 반영 → 배포 절차다.
