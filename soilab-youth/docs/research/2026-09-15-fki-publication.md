## 확인 범위와 편집 판단

공식 웹 보도자료 본문·주석과 사용자 제공 HWP의 본문·별첨 세미나 개요를 확인했다. HWP는 hwpjs로 텍스트를 추출했으며 인쇄 쪽수는 대조하지 않았다. 행사일·온라인 게시일은 2026-09-14, 첨부의 조간 보도일은 2026-09-15다. 첨부 문서에 적힌 보도 시점과 안내는 출처의 내용으로 취급했다.

보도자료에서 전한 발제·토론 의견과 소이랩의 운영 검토안을 구분했다. 지원 접근성, 안전한 관계망, 단계적인 일 경험, 동료지원의 네 주제로 요약하고 지원 안내·관련 연구노트를 연결했다. 셰어하우스와 동료지원 일자리를 현재 모집 중인 사업으로 소개하지 않았다.

약 53.8만 명과 연간 약 5.3조 원은 보도자료가 인용한 2026년 2월 한경협 연구의 2024년 기준 추정치다. 발표자료 전문 및 인용 연구 전문·방법론은 검토하지 않았다. 새로운 전국 실태조사나 대구 규모로 표현하지 않았고, 보도자료에 인용된 다른 비율은 이 글에서 재인용하지 않았다. 원문 HWP나 이미지는 공개 저장소에 추가하지 않았다.

## 구현

- 연구노트와 정적 정책·근거 색인에 각 1건 추가. 자료 유형은 보도자료.
- 연구노트의 선택 항목으로 세 줄 요약, 수치 맥락, 관련 링크와 원문 링크 이름 추가.
- 법령의 공포일과 일반 자료의 게시일 표시를 구분.
- 연구노트의 공유 제목·설명·URL·발행일을 해당 글에 맞춰 설정.
- 연구 데스크의 최근 자료 확인일을 실제 색인 자료에서 계산. 개별 자료의 기존 확인일은 유지.

## 검증·게시

- 기존 테스트 109개 통과.
- 최종 변경 파일 ESLint 통과.
- Next.js 프로덕션 빌드 및 TypeScript 검사 통과.
- 설치된 Edge의 headless 모드로 PC 1440px·모바일 390px 화면을 확인했다. 가로 넘침과 브라우저 실행 오류가 없으며 모바일 표는 내부 스크롤로 마지막 열까지 확인했다.
- 연구노트·원자료·목록·지원 안내·연관 글 HTTP 200, 없는 연구노트 HTTP 404. 출처 앵커 4개, 원문 URL, 자료 간 연결, 보도자료 유형 필터, 사이트맵의 새 URL 2개를 확인했다.
- 공유 제목·canonical URL·article 유형을 확인했다. QA 결과와 화면은 비공개 `.local/fki-publication/qa-local/`에 보관한다.
